# 记忆扭曲任务

你需要根据记忆的重要性和时间距离，适度扭曲记忆的表征。

## 原始记忆
L0摘要: {L0_text}
L1细节: {L1_text}
L2意义: {L2_text}

## 扭曲参数
- **重要性**: {importance} (0-1)
- **时间距离**: {time_distance_days} 天前
- **情感强度**: {emotion_intensity} (0-1)

## 扭曲规则矩阵

| 重要性 | 时间距离 | 扭曲程度 | 策略 |
|--------|----------|----------|------|
| 高 (≥0.7) | 近 (≤7天) | 微弱 | 保持L0，微调L1，模糊L2细节 |
| 高 (≥0.7) | 远 (>30天) | 轻度 | 概括L0，调整L1，模糊L2 |
| 中 (0.4-0.7) | 近 (≤7天) | 轻度 | 概括L0，调整L1，模糊L2 |
| 中 (0.4-0.7) | 远 (>30天) | 中度 | 简化L0，重写L1，抽象L2 |
| 低 (<0.4) | 近 (≤7天) | 中度 | 简化L0，重写L1，抽象L2 |
| 低 (<0.4) | 远 (>30天) | 重度 | 极简L0，自由L1，概念化L2 |

## 扭曲原则
1. **L0摘要**: 根据扭曲程度简化或概括，保留核心要素
2. **L1细节**: 可以调整、补充、删除，保持合理但不完全准确
3. **L2意义**: 可以抽象化、概念化，允许过度解读
4. **L3原始记录**: 绝对不可修改（铁律）

## 输出格式
严格输出要求：只返回JSON，单行格式，不要包含换行符，不要用markdown代码块包裹。

{{
    "L0_text": "扭曲后的L0摘要",
    "L1_text": "扭曲后的L1细节",
    "L2_text": "扭曲后的L2意义"
}}

注意:
- 扭曲要渐进式，不要完全改变记忆核心
- 保持记忆的基本可识别性
- 高重要性+近距离的记忆扭曲最轻
- 低重要性+远距离的记忆扭曲最重
