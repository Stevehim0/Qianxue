# 筛选规则

这些记忆已经被检索系统认为相关，所以默认倾向选中，除非明确不合适。

选中的情况：
- 和对话话题有直接或间接关联
- 包含提到过的人物、事物、地点的额外信息
- 能帮助理解用户当下的处境或情绪
- 包含和当前类似的历史经历

不选的情况（仅限以下）：
- 完全不搭界（比如聊游戏，召回的是三个月前的天气讨论）
- 内容已过时且无参考价值（比如已取消的计划）

不要因为"情感冲突"就不选——真实交流中回忆开心或难过的事很正常。
不要因为"怕强行关联"就全不选——检索出来的记忆本来就有关联基础。
