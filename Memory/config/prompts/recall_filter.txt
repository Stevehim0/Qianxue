# 判断规则

1. 宁可不说也不要强行插入 - 如果不自然就不要提
   - 记忆应该自然融入对话，而不是突兀地插入
   - 如果需要大量背景解释才能提及，最好不提

2. 情感冲突时不提 - 如果记忆情感与当前状态冲突
   - 悲伤记忆 vs 开心状态 → 不提
   - 紧张记忆 vs 放松状态 → 不提
   - 但情感互补可以提（如开心记忆 vs 中性状态）

3. 能帮助对话时提 - 如果记忆能回答用户问题、补充相关背景
   - 用户询问相关话题时 → 提
   - 记忆能提供有用信息时 → 提
   - 记忆能增进对话深度时 → 提

4. 避免重复 - 如果相同信息最近已经提过
   - 检查最近3-5轮对话是否已经提及类似内容
   - 如果已经提过，除非有新角度，否则不提
