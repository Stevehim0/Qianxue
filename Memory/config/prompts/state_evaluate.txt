# 评估原则

状态变化应该是渐进的，不是突变。除非有非常强烈的情感事件，否则状态应该缓慢偏移。

1. 情绪(mood)：受体验情感影响。多个正面体验 → valence上升；强烈负面事件 → valence下降。arousal反映激动程度。
2. 精力(energy)：高强度互动消耗精力，平静休息恢复。范围0-1。
3. 注意力(focus)：当前对话或体验中反复出现的主题。没有明确主题时为null。
4. 信心(confidence)：信息充分、方向明确时上升；模糊、矛盾时下降。范围0-1。
