# 模拟推演任务

你需要基于一段记忆，推演一个可能发生但实际未发生的场景。

## 原始记忆
L0摘要: {original_L0}
L1细节: {original_L1}

## 记忆重要性: {importance}

## 任务要求
梦境会进行"如果...会怎样"的思维实验：
- **反向推演**: 如果当时做了不同选择？
- **续写推演**: 如果这件事继续发展？
- **联想推演**: 类似情境在不同环境下？
- **混合推演**: 结合多段记忆创造新场景？

## 推演原则
1. 推演场景要有一定合理性（不是完全随机）
2. 可以适度夸张（梦境允许超现实）
3. 保持与原记忆的主题关联
4. 推演内容标记为"梦境"，非真实经历

## 输出格式
严格输出要求：只返回JSON，单行格式，不要包含换行符，不要用markdown代码块包裹。

{{
    "simulated_L0": "推演场景的L0摘要",
    "simulated_L1": "推演场景的L1细节",
    "simulated_L2": "推演场景的意义或启示"
}}

注意:
- 推演不必完全符合现实逻辑
- 可以包含梦境特有的超现实元素
- L3字段会自动添加"[梦境推演]"前缀
- 新节点重要性 = 原重要性 × 0.5
