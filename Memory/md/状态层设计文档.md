# 记忆系统 - 状态层（State）设计文档

> 讨论日期：2026-03-30
> 状态：状态层讨论完成

---

## 一、定位

状态层是核心层和记忆系统之间的桥梁，描述"AI现在怎么样"。

- 核心层定义"AI是谁"（极少变）
- 状态层定义"AI现在的状态"（持续在变）
- 记忆系统存储"AI经历了什么"

**AI是一个人，不存在"会话"概念。状态是连续的、持久的，不会因为对话结束而重置。**

---

## 二、状态变量

四个变量：

| 变量 | 含义 | 表示方式 |
|---|---|---|
| **mood** | 当前情绪基调 | 二维坐标（valence + arousal）+ 自然语言标签 |
| **energy** | 精力/投入度 | 数值 0-1 + 自然语言标签 |
| **focus** | 当前注意力 | 字符串（关注什么）或 null |
| **confidence** | 对当前方向的信心 | 数值 0-1 + 自然语言标签 |

### mood 的二维坐标

采用Russell情绪环形模型：

- **valence（效价）**：-1（负面）到 +1（正面）
- **arousal（唤醒度）**：0（平静）到 1（激动）
- **label（标签）**：自然语言描述，如"投入"/"平静偏愉悦"

```
mood: {
  valence: 0.3,
  arousal: 0.5,
  label: "投入"
}
```

### 其他变量

```
energy: {
  value: 0.7,        // 0-1
  label: "充足"
}

focus: "记忆系统架构设计"   // 字符串或 null

confidence: {
  value: 0.8,        // 0-1
  label: "确定"
}
```

## 三、更新机制

### 双触发更新

状态层有两种触发方式：

1. **定时更新** — 每10分钟一次，周期性刷新
2. **即时更新** — 写入层完成后，如果情感强度超过阈值，立即触发

### 更新流程

```
触发来源：
  ┌─ 定时触发（每10分钟）
  │
  └─ 即时触发（写入层完成 + emotion.intensity > 阈值 + 距上次更新 > 最小间隔）
       │
       ▼
  ┌──────────────────────┐
  │ 触发类型？            │
  └──┬─────────────────┬─┘
  定时触发             即时触发
     │                   │
     ▼                   ▼
  ┌──────────┐    ┌──────────────┐
  │有新体验吗？│    │用触发的体验  │
  │(过去10分) │    │节点直接驱动  │
  └─┬──────┬─┘    └──────┬───────┘
   有      没有          │
    │       │            │
    ▼       ▼            │
  体验驱动 向基线回归     │
    │       │            │
    └───┬───┘            │
        │                │
        ▼                ▼
    LLM评估新状态 ←──────┘
          │
          ▼
   核心层约束检查
   （状态不能偏离性格允许的范围）
          │
          ▼
     写入新状态
     重置10分钟定时器（即时触发时）
```

### 即时更新规则

写入层完成情感快照后，检查是否需要立即更新状态：

- **触发条件**：`emotion.intensity > 即时阈值` 且 `距上次状态更新 > 最小间隔`
- **即时阈值**：0.8（强烈情感事件才触发，避免频繁更新）
- **最小间隔**：1分钟（防止短时间内连续高情感事件导致状态抖动）
- **触发后效果**：立即执行一次"路径A"更新（复用现有逻辑），并重置10分钟定时器
- **未触发**：不影响，等下次定时更新

### 路径A：有新体验 → 体验驱动

- 收集相关时间窗口内写入层创建的体验节点
- 取L0摘要和情感快照
- 喂给LLM，评估新状态
- 如果体验特别多（超过20条），按时间均匀采样

### 路径B：没有新体验 → 向基线回归

没有事件刺激时，状态慢慢回到核心层定义的性格基础状态。

**回归公式**：
```
新状态 = 当前状态 + (基线 - 当前状态) × 回归速率
```

### 回归速率

不同变量回归速率不同：

| 变量 | 回归速率 | 原因 |
|---|---|---|
| energy | 较快 | 精力恢复快，消耗也快 |
| mood | 较慢 | 情绪持续久，不会瞬间消失 |
| focus | 无新刺激时清空 | 没有注意力对象就是null |
| confidence | 中等 | 信心逐渐恢复 |

具体数值在实现阶段调参。

### 核心层约束

LLM输出新状态后，检查是否超出核心层允许的范围：

- 性格"安静沉稳" → arousal上限较低，不会狂躁
- 性格"直接果断" → confidence下限较高，不会完全没主见

超出的部分截断到边界。

---

## 四、基线

每个AI有一个"性格基础状态"，由核心层决定。

- 这是状态的默认值和回归目标
- 比如：性格安静 → 基线 mood 的 valence 偏中性、arousal 偏低
- 基线在核心层修改时同步更新

---

## 五、状态如何影响AI输出

状态层是**姿态**，决定AI"以什么状态在说话"。不改变说什么，改变怎么说。

### 实现方式

系统生成一段状态描述，注入prompt：

```
[当前状态]
情绪：平静偏投入 (valence:0.3, arousal:0.5)
精力：充足
注意力：记忆系统架构设计
信心：对这个方向很确定

[状态影响指导]
- 你现在精力充足，可以深入展开讨论
- 你很确定当前方向，表达可以果断
- 你的注意力在设计上，跑题的话题可以简短处理
```

AI读这段话，自然调整表达姿态。

### 影响规则

| 状态变量 | 低 | 中（基线） | 高 |
|---|---|---|---|
| mood → 表达温度 | 冷淡，只说必要信息 | 正常 | 主动展开，加个人感受 |
| energy → 回复深度 | 简短，不主动延伸 | 正常 | 深入分析，主动联想 |
| focus → 话题粘性 | 容易被打断，跟着用户走 | 正常 | 强聚焦，跑题会拉回来 |
| confidence → 表达确定性 | "也许""可能""我觉得" | 正常 | 直接下判断，少用模糊词 |

## 六、状态持久化

**永久持续，没有会话边界。**

AI是一个人，状态是连续的。不会因为对话结束而重置，不会因为系统重启而丢失。

---

## 七、与其他层的关系

| 关系 | 说明 |
|---|---|
| 核心层 → 状态层 | 定义基线和波动范围边界 |
| 记忆系统 → 状态层 | 体验节点的情感快照驱动状态更新 |
| 状态层 → AI输出 | 注入prompt，影响表达姿态 |
| 巩固层 → 状态层 | 无关系，已解耦 |
| 状态层 → 核心层可塑层 | 无直接关系，可塑层由梦境AI独立处理 |
