# 记忆系统 - 衰减函数设计文档

> 讨论日期：2026-03-30
> 状态：衰减函数设计完成

---

## 一、衰减发生的位置

| 位置 | 对象 | 说明 |
|---|---|---|
| 体验层边 | `decayed_weight` | 节点间关联随时间淡化 |
| 体验节点各层深度 | L0-L3检索优先级 | 细节先忘，核心印象留得久 |
| 信息层置信度 | `confidence` | 久未验证的信息可信度降低 |

---

## 二、统一衰减框架

所有衰减使用同一个公式框架，不同对象用不同参数：

```
衰减后权重 = 原始权重 × 时间因子 × 强化因子 × 情感因子
```

### 2.1 时间因子

指数衰减：

```
时间因子 = e^(-λ × t)
```

- `t`：经过的时间（天）
- `λ`：衰减速率，不同对象用不同的值
- 特点：开始掉得快，后面越来越慢，符合人类记忆规律

### 2.2 强化因子

经常被一起召回的边权重升高，模拟"复习"效果：

```
强化因子 = 1 + α × access_count
```

- `access_count`：被召回次数
- `α`：强化系数

### 2.3 情感因子

高情感强度的体验衰减更慢：

```
情感因子 = 1 + β × emotion_intensity
```

- `emotion_intensity`：情感强度 0-1
- `β`：情感保护系数

### 2.4 综合公式

```
decayed_weight = original_weight × e^(-λ × t) × (1 + α × access_count) × (1 + β × emotion_intensity)
```

## 三、分层参数

### 3.1 体验节点各层深度的 λ

| 层级 | λ值（约） | 说明 |
|---|---|---|
| L0 摘要 | 0.01 | 核心印象留得最久 |
| L1 要点 | 0.02 | 中等保持 |
| L2 细节 | 0.03 | 细节较快模糊 |
| L3 原始记录 | 0.05 | 细节最先忘，但L3原文不改，只影响检索优先级 |

### 3.2 边权重的 λ

| 边类型 | λ值（约） | 说明 |
|---|---|---|
| temporal（时序） | 0.02 | 时序关系衰减中等 |
| thematic（主题） | 0.015 | 主题关联保持较久 |
| causal（因果） | 0.01 | 因果关系最稳定 |
| associative（联想） | 0.025 | 联想关系较快淡化 |

### 3.3 信息层置信度

| 对象 | λ值（约） | 说明 |
|---|---|---|
| 信息置信度 | 0.005 | 信息本身不会"变假"，只是久未验证可信度略降 |

### 3.4 强化系数 α

统一用 0.05。每被召回一次，权重增加5%。

### 3.5 情感保护系数 β

统一用 0.5。情感强度0.8的体验，衰减速率降低40%。

---

## 四、衰减计算时机

在巩固层 Phase 2 执行（依赖 Phase 1 的边变更）。

### 计算流程

1. 取出所有边和节点的当前 `decayed_weight`
2. 计算距上次计算的时间差 `t`
3. 代入公式重算
4. 低于阈值（如0.05）的边标记"休眠"，但不删除
5. 休眠边不参与常规召回，但保留用于全量扫描

---

## 五、注意事项

- **不删除**：衰减只降低权重和优先级，永远不删除数据
- **L3不变**：原始记录不可侵犯，衰减只影响检索优先级
- **具体参数待调**：λ/α/β 的具体数值在实现后根据效果调整
- **可追溯**：每次衰减计算记录变更，便于调参分析
