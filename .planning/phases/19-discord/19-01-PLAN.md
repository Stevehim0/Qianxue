**Key class structure:**

```python
"""Discord message source -- convert Discord messages to AgentMessage format."""

import asyncio
import io
import logging
from typing import Optional, Callable, Awaitable

import discord
from discord.ext import commands

from backend.config import settings
from backend.services.agent.message import AgentMessage
from backend.services.voice_service import voice_service, VoiceError

logger = logging.getLogger(__name__)
```

**DiscordSource class with these methods:**

1. `__init__(self)` -- reads config from `settings.discord`. Sets up intents (message_content=True, dm_messages=True). Initializes `_bot=None`, `_task=None`, `_message_handler=None`.

2. `set_message_handler(self, handler: Callable[[AgentMessage], Awaitable[None]])` -- sets the callback that receives converted AgentMessages (Brain's entry point).

3. `connect(self) -> None` -- async. Creates new Bot instance, registers handlers, starts via `asyncio.create_task(self._bot.start(token))`. Idempotent: if already connected, return immediately. Token from `settings.discord.token`.

4. `disconnect(self) -> None` -- async. Closes bot, cancels task, sets `_bot=None, _task=None`.

5. `is_connected(self) -> bool` -- returns `self._bot is not None and self._bot.is_ready()`.

6. `_register_handlers(self)` -- called during connect(). Registers `on_message` and `on_ready` events on the current bot instance.

7. `_handle_message(self, message: discord.Message)` -- filters (ignore self, check channel/DM), calls `_convert_message`, then calls `_message_handler`.

8. `_should_process(self, message: discord.Message) -> bool` -- DMs always processed (if dm_enabled), channels only if in configured list (`settings.discord.channels`).

9. `_convert_message(self, message: discord.Message) -> Optional[AgentMessage]` -- maps Discord fields to AgentMessage per RESEARCH R-03 mapping table:
   - `source="discord"`
   - `group_id`: `f"dm_{message.author.id}"` for DM, `str(message.channel.id)` for channel
   - `user_id=str(message.author.id)`
   - `sender_nickname=message.author.display_name`
   - `content=message.content` (may be augmented with voice transcription)
   - `raw_message=f"discord:{message.id}"`
   - `is_mentioned`: check `self._bot.user in message.mentions`
   - `mentions`: list of `{"id": str(m.id), "name": m.display_name}`
   - `is_private`: `message.guild is None`
   - `timestamp=message.created_at`
   - `priority=10 if is_mentioned else 0`
   Then detect voice attachments (see below).

10. `_find_voice_attachment(self, message: discord.Message) -> Optional[discord.Attachment]` -- checks `.ogg` files and `audio/*` content_type attachments.

11. `_transcribe_voice(self, attachment: discord.Attachment) -> Optional[str]` -- downloads to BytesIO, passes bytes to `voice_service.transcribe(audio_bytes)`. Catches VoiceError, logs warning, returns None on failure.

12. `send_message(self, channel_id: str, text: str, is_private: bool = False) -> bool` -- sends text to Discord channel or DM. For DM, extract user_id from `dm_` prefix, use `self._bot.fetch_user()` (not get_user, which may miss uncached users). For channel, use `self._bot.get_channel()`. Handles Discord 2000-char limit by splitting at newline boundaries.

13. `send_voice_file(self, channel_id: str, audio_bytes: bytes, filename: str = "voice_reply.mp3", is_private: bool = False) -> bool` -- for Phase 18 send_voice tool integration. Sends audio file as Discord attachment. Phase 19 creates the method signature but actual usage is Phase 20.

**Voice attachment processing flow (per D-07, D-08):**
In `_convert_message`, after building base AgentMessage:
```python
voice_attachment = self._find_voice_attachment(message)
if voice_attachment and settings.discord.voice.auto_transcribe:
    if voice_attachment.size <= settings.discord.voice.max_size:
        agent_msg.has_voice = True
        agent_msg.voice_url = voice_attachment.url
        transcription = await self._transcribe_voice(voice_attachment)
        if transcription:
            agent_msg.voice_transcription = transcription
            if agent_msg.content.strip():
                agent_msg.content = f"{agent_msg.content}\n[语音消息转写] {transcription}"
            else:
                agent_msg.content = f"[语音消息转写] {transcription}"
```
