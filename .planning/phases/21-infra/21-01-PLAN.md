    **模块结构：**
    ```python
    """语音依赖健康检查模块.

    在 backend main.py lifespan 中调用，检查 5 项语音依赖：
    - FunASR WebSocket (D-07)
    - FFmpeg (D-08)
    - Opus (D-09)
    - Edge-TTS (D-10)
    - discord-ext-voice-recv (D-11)

    所有检查失败仅 WARNING，不阻塞启动 (D-04)。
    """
    ```

    **函数签名：**
    ```python
    async def check_funasr(url: str, timeout: float = 5.0) -> tuple[bool, str]:
    async def check_ffmpeg(timeout: float = 5.0) -> tuple[bool, str]:
    async def check_opus() -> tuple[bool, str]:
    async def check_edge_tts(voice: str, timeout: float = 10.0) -> tuple[bool, str]:
    def check_voice_recv() -> tuple[bool, str]:
    async def check_voice_dependencies() -> dict[str, tuple[bool, str]]:
    ```

    **各检查实现：**

    1. **check_funasr** (D-07): 使用 `websockets.connect(url, timeout=timeout)` 尝试连接 WebSocket。成功返回 `(True, "OK")`。失败返回 `(False, "不可用: {url} ({error})")`。使用 `try/except Exception` 捕获所有错误。

    2. **check_ffmpeg** (D-08): 使用 `asyncio.create_subprocess_exec('ffmpeg', '-version', stdout=PIPE, stderr=PIPE)` 启动子进程。`await asyncio.wait_for(proc.wait(), timeout=timeout)`。returncode==0 返回 `(True, "OK")`。FileNotFoundError 返回 `(False, "未找到 ffmpeg。请安装: https://ffmpeg.org/download.html")`。TimeoutError 返回 `(False, "ffmpeg 检查超时")`。

    3. **check_opus** (D-09): 先检查 `discord.opus.is_loaded()`。若 False，尝试 `discord.opus.load_opus('opus')`。再次检查 `is_loaded()`。True 返回 `(True, "OK")`。False 返回 `(False, "libopus 未加载。请下载 opus.dll 放到工作目录或系统 PATH")`。任何异常捕获返回 `(False, str(e))`。

    4. **check_edge_tts** (D-10): 使用 `edge_tts.Communicate("测试", voice)` 创建通信对象。调用 `async for chunk in communicate.stream()`，检查 `chunk["type"] == "audio"`。获取到第一个 audio chunk 即返回 `(True, "OK")`。使用 `asyncio.wait_for(整体检查, timeout=timeout)` 包裹。失败返回 `(False, "Edge-TTS 不可用: {error}")`。

    5. **check_voice_recv** (D-11): 尝试 `from discord.ext import voice_recv`。成功返回 `(True, "OK")`。ImportError 返回 `(False, "未安装。请运行: pip install discord-ext-voice-recv")`。

    6. **check_voice_dependencies**: 编排函数。从 `settings.voice` 读取配置，依次调用以上 5 个检查。每项检查结果通过 `logger.info/warning` 输出，格式统一为 `[语音依赖] {name}: {OK/WARNING} — {detail}` (D-06)。返回 dict `{"funasr": (bool, str), "ffmpeg": (bool, str), "opus": (bool, str), "edge_tts": (bool, str), "voice_recv": (bool, str)}`。

    **注意：** Edge-TTS 检查涉及实际网络请求，超时设为 10 秒。FunASR 检查使用 settings.voice.funasr_websocket_url 作为连接地址。

    然后创建 `tests/test_voice_health.py`，对每个检查函数编写 mock 测试（按 behavior 块中的 10 个测试用例）。使用 `unittest.mock.patch` mock `websockets.connect`、`asyncio.create_subprocess_exec`、`discord.opus.is_loaded`、`edge_tts.Communicate`、`importlib.util.find_spec` 等。使用 `pytest` + `pytest-asyncio`。
